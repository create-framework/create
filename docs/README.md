# User guide

How to use Create, topic by topic. New to it? Start with the [README](../README.md)'s
"Hello, world!" and the programs under [examples/](../examples/).

- [Programs](programs.md): how a program runs, `create` and `update`, `run`'s arguments and the
  CPU or GPU backend, screens, what is a field and what a parameter, and the calls each frame
  needs.
- [Coordinates, camera and autoscale](coordinates.md): where things are on screen, the camera,
  the design size, and the run's settings on `Context`.
- [Drawing](drawing.md): shapes and your own drawable types, the background, transforms,
  antialiasing and clipping.
- [Style](style.md): colours, strokes, gradients, shadows, tint and blend modes, and text.
- [Pixels and recording](pixels.md): reading back what was drawn, offscreen canvases, images,
  and recording GIFs.
- [Input](input.md): the keyboard, mouse and gamepads, and text entry.
- [Geometry](geometry.md): the shapes and curves, and collision tests between them.
- [Math, time and randomness](math.md): points and vectors, random numbers and noise, easing
  and tweens, and the clocks.
- [Data](data.md): CSV/TSV tables and JSON.
- [Audio](audio.md): loading and synthesizing sounds, playing them, and controlling each
  playback.
