# Math

The mathematics behind moving, turning and shaping things, explained from the beginning: these
pages assume no prior knowledge. Angles, vectors and matrices build on each other, so they read
best in that order.

- [Angles](angles.md): radians, and turning angles into directions.
- [Vectors](vectors.md): points, movements, length and direction.
- [Matrices](matrices.md): moving, turning and scaling with matrices.
- [Interpolation](interpolation.md): finding values in between, with `lerp`, `map` and more.
- [Easing](easing.md): giving a movement character.
- [Random](random.md): random numbers and seeds.
- [Noise](noise.md): values that vary randomly but smoothly.
