# Maths

The mathematics behind moving, turning and shaping things. Each page explains its topic from the
beginning, assuming only basic school maths, such as negative numbers, multiplication and square
roots. Angles, vectors and transforms build on each other, so they read best in that order.

- [Angles](angles.md): radians, and turning angles into directions.
- [Points and vectors](points-and-vectors.md): points, movements, length and direction.
- [Transforms](transforms.md): moving, turning and scaling what you draw, and matrices.
- [Interpolation](interpolation.md): finding values in between, with `lerp`, `map` and more.
- [Easing](easing.md): giving a movement character.
- [Random numbers](random-numbers.md): getting them, and seeds that repeat them.
- [Noise](noise.md): values that vary randomly but smoothly.
