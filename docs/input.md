# Input

| Term | Meaning |
|---|---|
| Down / pressed / released | One vocabulary for every device: `context.keyboard`, `context.mouse` and `context.gamepad(i)` each answer `down(button)`, `pressed(button)` and `released(button)` (the mouse's default to `LEFT`). *Down* is held right now, true every frame; *pressed*/*released* are edges, true only in the frame it went down or came up. Unlike Processing's `mousePressed`, *pressed* never means held. When the window loses focus everything held is released, each with its *released* edge, since what is let go while it is away is never reported to it; a disconnecting pad releases its buttons the same way. The most recent press is `keyboard.key`, `mouse.button` and `pad.button`, each `Key`/`MouseButton`/`GamepadButton.NONE` before any — typed, like every enum, so a bare number never passes for a key, button or `FontWeight` |
| `Key` | A key **by position**, not by label: each constant names where a key sits on a US layout, so `Key.W` is the key above `S` (AZERTY's Z) and WASD lands under the same fingers on every layout. Characters never come from a `Key`; they are `context.keyboard.text`. `Key.from_name` reads a binding from a file (`"page_up"`, `"a"`, `"/"`), as do `MouseButton.from_name`, `GamepadButton.from_name` and `Cursor.from_name`, each by its constants' names, case folded. `CTRL`/`SHIFT`/`ALT`/`SUPER` match either side |
| `Mouse` | `context.mouse`: `position` and `press_position` (`Point2D`s, screen space), `wheel` (this frame's scroll, added up) and `movement` (how far the pointer moved this frame, y up, in screen units). `movement` keeps counting where `position` stops — at the screen's edge, and while `context.lock_mouse(True)` hides the pointer and holds it in the window for a first-person camera; unlock it for a menu. `context.cursor(...)` sets the pointer's look |
| `Gamepad` | `context.gamepad(i)`, a copy of player `i`'s pad (default 0). A pad takes the lowest free slot as it connects and keeps it until it disconnects; an empty slot reads `connected` False and all zero, so no check is needed first. Sticks are `Vector2D`s, **y up**, inside the unit circle, with a rescaled radial dead zone (`Gamepad.STICK_DEAD_ZONE`, 0.2) so a resting stick reads exactly zero; triggers 0..1. Face buttons are positional (`GamepadButton.SOUTH` is Xbox A and PlayStation Cross). Each trigger is also a button, `GamepadButton.LEFT_TRIGGER`/`RIGHT_TRIGGER`, down from `Gamepad.TRIGGER_PRESS` (0.5) and up again below `TRIGGER_RELEASE` (0.4), so `pad.pressed(GamepadButton.RIGHT_TRIGGER)` fires once per pull. `connected_this_frame`/`disconnected_this_frame` are the edges of `connected`, and `name` survives the frame a pad leaves in. `context.rumble(seconds, low_frequency=, high_frequency=, player=)` shakes a pad (both motors full by default; a new rumble replaces the running one); it is an output, so it lives on `Context`, not on the `Gamepad` copy. See [examples/gamepad/main.mojo](../examples/gamepad/main.mojo) |
| Typed / `text` | Text entry. `keyboard.typed(key)` is pressed or auto-repeated while held, for editing keys (Backspace, arrows); `context.keyboard.text` is this frame's typed characters, UTF-8, with shift, layout and IME applied — append it, don't rebuild it from keys. Both reset every frame. Taking text is on by default and also opens an IME's composition window and a handheld's on-screen keyboard, so a game played on letter keys switches it off with `context.text_input(False)` (keys read the same; only `text` goes quiet) and on again while a field is in use. `EditableText` does the editing: `field.update(context)` each frame replays the frame's typing in the order it came (so text and keys typed within one frame land where they were typed) and keeps `text`, a caret and a selection, whole characters at a time — Shift extends the selection, a word modifier (Option on macOS, Ctrl elsewhere) moves and deletes by words, and the command shortcuts (Cmd on macOS, Ctrl elsewhere; by the key's label, not its position) select all, copy, cut and paste through `context.clipboard()`/`context.clipboard(text)`, the system clipboard. `max_length=` caps what typing and pasting add. `canvas.text_width(field.before_caret())` places the caret, `before_selection()`/`selected_text()` the selection's highlight. It lives in `core`, beside the `Context` it reads. See [examples/typing/main.mojo](../examples/typing/main.mojo) |
