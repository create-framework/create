# Spacing

```mojo
struct Spacing
```

The theme's gaps, from `small`, between a label and its widget, to `large`, between groups of widgets.

Implements `Copyable`, `Deinitable`, `ImplicitlyCopyable`, `Movable`, `Writable`.

- `medium: Float64`
