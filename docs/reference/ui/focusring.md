# FocusRing

```mojo
struct FocusRing
```

The ring drawn around a widget focused from the keyboard or a gamepad: its `thickness`, and the `gap` between it and the widget.

Implements `Copyable`, `Deinitable`, `ImplicitlyCopyable`, `Movable`, `Writable`.

## Fields

- `thickness: Float64`
- `gap: Float64`
