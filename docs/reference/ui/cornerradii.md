# CornerRadii

```mojo
struct CornerRadii
```

How round the theme's corners are, from `small`, such as a checkbox's, to `large`, such as a panel's.

Implements `Copyable`, `Deinitable`, `ImplicitlyCopyable`, `Movable`, `Writable`.
