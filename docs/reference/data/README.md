# create.data

Data files: `Table` and `TableRow` for CSV and TSV, and `JSON`.

## Types

| Type | Description |
|---|---|
| [`Table`](table.md) | Rows of text cells read from CSV or TSV, like Processing's `Table`. |
| [`TableRow`](tablerow.md) | One row of a `Table`, its cells reached by column name or index. |
| [`JSON`](json.md) | A JSON value: an object, array, string, number, bool or null. |
| [`JSONKind`](jsonkind.md) | Which of JSON's six kinds of value a `JSON` holds. |
