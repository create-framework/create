# create.time

Time: the run's frame clock (`Time`), the `Clock` a playhead keeps time by, and the wall clock (`DateTime`).

## Types

| Type | Description |
|---|---|
| [`Time`](time.md) | Per-frame timing, ticked once per frame by the run loop. |
| [`Clock`](clock.md) | The run's scaled time or its real time, for a playhead to keep time by. |
| [`DateTime`](datetime.md) | A calendar date and local time of day, read all at once. |
